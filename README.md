# Shoreline
1. Create a new private GitHub repo and upload everything in this folder (keep the .github folder).
2. Open the repo's Actions tab, pick "Build APK", press Run workflow (it also runs on every push).
3. When it finishes (about 5 min), open the run and download the "shoreline-apk" artifact. Unzip it.
4. Copy app-debug.apk to the phone, open it, allow "install unknown apps" for your file manager or browser.
5. On first launch allow notifications and location (location is only used for the day's weather).
If the build fails, send me the red error lines from the Actions log.
